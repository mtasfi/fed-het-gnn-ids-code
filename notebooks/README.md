# Notebooks (Kaggle / Colab)

This folder has one notebook per experiment, named `<ID>_<name>.ipynb`. All of them are generated by `tools/make_notebooks.py`. To change the setup, edit that script and regenerate:

```bash
python tools/make_notebooks.py
```

## First cell: the only thing you edit

| variable | meaning |
|---|---|
| `PLATFORM` | `"kaggle"` or `"colab"`. The same notebook runs on both platforms |
| `BRANCH` | branch of `mtasfi/fed-het-gnn-ids-code` to clone (default `main`) |
| `DATA_ROOT` | ToN-IoT location: an attached Kaggle dataset, or a folder on Google Drive |
| `STATE_DIR` | persistent state: `work/` (E0 outputs, embedding caches, Phase-1 checkpoints), `runs/`, `results/` |
| `RESTORE_FROM` | Kaggle only: an attached dataset holding earlier state, which is copied into `STATE_DIR` |
| `LOCKED` | values locked after E0: `partition.alpha`, `partition.alpha_sweep`, `graph.shares_host.kappa` |
| `SEEDS`, `SMOKE`, `RESUME`, `OVERWRITE` | same as the `run.py` flags |

The GitHub token is read from `GITHUB_TOKEN`. The notebook checks, in order, an environment variable, a Kaggle Secret, and a Colab secret. The token is used only in the clone URL and is then removed from `.git/config`.

## Using two platforms in parallel

- Notebooks that need only E0 can run on either platform as soon as the E0 state is present there:
  A1, A2, A3, B1, B2, B5 and E5.
- Notebooks that need E1 must see E1's `work/<ds>/cache/` and `runs/E1/`.
- **Moving state between the two:**
  - Colab keeps `STATE_DIR` on Google Drive.
  - Kaggle writes it to `/kaggle/working/fhf_state`. Save the notebook version, create a dataset from its output, then either attach that dataset elsewhere and set `RESTORE_FROM`, or copy it to `MyDrive/fhf_state` for Colab.
- Run directories are keyed by experiment, variant, alpha and seed, and completed runs are immutable. So a run done on one platform is never overwritten by the other. Copying states together is enough to merge them; then run `AGG_aggregate_results`.
- Every round is checkpointed. If a Kaggle session hits its limit, set `RESUME = True` and rerun the same notebook.
